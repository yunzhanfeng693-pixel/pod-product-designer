# POD产品设计器

POD产品设计器是一款用于制作服装产品效果图的本地工具。可以管理正反面胚衣、导入透明 PNG 贴图，在画布中调整位置、大小和角度，然后导出合成图片。

作者：lufan  
许可证：MIT

## 运行环境

- Windows 10 或 Windows 11
- Node.js 18 或更高版本
- 推荐使用 Chrome 或 Edge 浏览器

## 安装和启动

第一次使用时，在项目目录中打开 PowerShell，依次运行：

```powershell
npm install
npm run dev
```

终端显示本地访问地址后，在浏览器中打开该地址。常见地址为：

```text
http://localhost:5173
```

开发服务器运行期间不要关闭 PowerShell 窗口。需要停止时，在窗口中按 `Ctrl+C`。

## 界面说明

界面从左到右分为四个区域：

1. 胚衣库：选择、添加和管理产品底图。
2. 设计画布：调整贴图的位置、大小和角度。
3. 设计贴图：导入单张 PNG，或从文件夹中选择图片。
4. 合成预览：查看正反面效果并下载成品图。

左右板块边缘可以拖动，用来调整板块宽度。“设计贴图”区域中间的横向分隔条可以上下拖动，用来改变当前图片和下方缩略图库的显示空间。

## 基本使用流程

### 1. 选择胚衣

在左侧“胚衣库”中选择分类和颜色，然后选择需要设计的胚衣。顶部的“正面”和“背面”按钮用于切换当前编辑面。

如果要添加自己的胚衣：

1. 打开胚衣编辑窗口。
2. 选择分类并填写颜色名称。
3. 上传正面图片。
4. 根据需要上传背面图片；未上传背面时会使用正面图片。
5. 点击“添加胚衣”保存。

建议正反面底图使用相同尺寸和构图，这样贴图位置更容易保持一致。

### 2. 导入设计贴图

设计贴图仅支持 PNG 格式，建议使用透明背景图片。

可以通过以下方式导入：

- 把 PNG 拖入“设计贴图”上传区域。
- 点击上传区域后选择单张 PNG。
- 点击“文件夹”，授权一个包含 PNG 的本地目录。

选择文件夹后，下方会显示缩略图库。鼠标左键单击任意缩略图即可使用。

已授权的文件夹每 3 秒静默检查一次。如果目录中增加了新的 PNG，图片会自动追加到缩略图库末尾。已有图片不会重新加载或改变顺序。使用浏览器备用文件夹选择方式时，由于浏览器限制，可能无法持续监测目录变化。

### 3. 调整贴图

在画布中可以直接操作当前贴图：

- 移动：按住贴图内部并拖动。
- 缩放：鼠标停在画布区域，滚动滚轮；向上放大，向下缩小。
- 调整大小：拖动画框边缘的控制点。
- 旋转：拖动画框四角的红色控制点。
- 精确缩放：在下方工具栏输入百分比。
- 快速旋转：使用工具栏中的左右旋转按钮。
- 恢复初始状态：点击重置按钮。

滚轮缩放范围为 1% 至 500%。在画布区域滚动时，只会调整贴图，不会带动右侧面板滚动。

正面和背面的贴图及变换参数分别保存，切换编辑面不会覆盖另一面的设计。

### 4. 查看和保存结果

右侧“合成预览”会在操作停止后自动更新，以免拖动时反复生成大图造成卡顿。

- 点击“下载”保存单张正面或背面图片。
- 点击“复制”把预览图复制到剪贴板，可粘贴到支持图片的应用中。
- 点击“快速保存”可以选择正面、背面，以及是否批量保存同分类的全部颜色。

浏览器版本会把文件保存到浏览器的默认下载目录。首次批量下载时，浏览器可能询问是否允许下载多个文件，请选择允许。

## 数据保存

胚衣、分类、颜色、当前贴图和变换参数保存在浏览器的 IndexedDB 中。项目源码中的默认胚衣位于：

```text
src/data/mockShirts.ts
```

请注意：

- 清除浏览器网站数据可能会删除自行添加的胚衣和设计记录。
- 更换浏览器、浏览器用户或本地访问端口后，可能看不到原来的数据。
- 更新源码、删除 `node_modules` 或重新生成 `dist` 不会主动清除 IndexedDB 数据。
- 重要胚衣和设计图应保留原始文件备份。

## 构建项目

生成网页生产文件：

```powershell
npm run build
```

构建结果位于 `dist` 目录。

构建 Windows Electron 安装包：

```powershell
npm run electron:build
```

安装包默认输出到 `dist-electron` 目录。执行 Electron 构建前，请确认 `public/favicon.ico` 已存在；如果不需要自定义图标，也可以先从 `package.json` 的 Electron 构建配置中移除图标项。

## 常见问题

### 页面无法打开

确认 `npm run dev` 所在的终端仍在运行，并使用终端实际显示的地址。如果依赖目录不存在，先运行 `npm install`。

### 图片无法加入缩略图库

确认文件扩展名为 `.png`。如果刚复制到已授权文件夹，请等待约 3 秒。

### 文件夹不再自动刷新

浏览器可能失去了目录读取权限。重新点击“文件夹”并选择该目录即可。

### 拖动或缩放后预览没有立刻变化

合成预览采用延迟更新。停止操作约四分之一秒后会自动生成新预览，也可以点击预览区域的刷新按钮。

### 关闭后自定义数据消失

不要使用无痕窗口，也不要清除该本地地址的网站数据。使用固定浏览器和固定端口启动，可以减少数据被分散到不同存储空间的情况。
